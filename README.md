# 🎧 VODCAST

VODCAST, React + Vite ile geliştirilmiş modern bir podcast, video içerik, canlı yayın ve blog platformudur. Projede backend yerine fake API ve mock data kullanılarak dinamik bir içerik sistemi oluşturulmuştur.

---

## 🚀 Özellikler

- 🎬 Podcast & video içerik listeleme sistemi  
- 🔴 Canlı yayın (Live streaming UI simülasyonu)  
- 📝 Blog bölümü (makale / içerik sistemi)  
- 📡 Fake API / mock data ile dinamik veri akışı  
- ⚡ Hızlı ve modern kullanıcı arayüzü (Vite + React)  
- 📱 Responsive (mobil uyumlu) tasarım  

---

## 🛠️ Kullanılan Teknolojiler

- React  
- Vite  
- JavaScript (ES6+)  
- CSS / Tailwind (kullandıysan)  
- Fake API / Mock Data
